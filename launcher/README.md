# Cardinal Launcher (тестовая версия 0.1.0)

Программа для FunPay Cardinal в стиле ProjectX Launcher: тёмный «терминал», зелёный акцент, та же левая панель и карточки.
Код бота не меняется: лаунчер запускает `main.py` как отдельный процесс и показывает его вывод.

## Запуск
Дважды щёлкните `ProjectX-FunPay.exe`. Это portable-версия: установка не нужна, Node.js не нужен.
Exe должен лежать в папке `CardinalLauncher` рядом с папкой бота `FunPayCardinal-main`, тогда он найдёт бота сам. Иначе укажите папку в настройках.

## Что умеет
- **Главная**: запуск, остановка и перезапуск бота, живая консоль, аптайм, PID, автоперезапуск после падения.
- **Плагины**: список из `plugins/`, включение и выключение через тот же `storage/cache/disabled_plugins.json`, что ведёт Cardinal (только при остановленном боте).
- **Логи**: хвост `logs/log.log` с фильтром по уровню и поиском.
- **Настройки**: папка бота, путь к Python (по умолчанию venv, `py -3`, `python`), автозапуск, трей, темы и акценты как в ProjectX.
- Если нет `configs/_main.cfg`, кнопка «Первая настройка» открывает обычную консоль Cardinal.

## Важно
Не запускайте бота одновременно через `Start.bat` и через лаунчер: будут два экземпляра на одном аккаунте.

## Сборка exe
`npm install`, затем `npm run build` создаст `dist/ProjectX-FunPay.exe` (portable). Иконку ставит `scripts/set-icon.js`.
