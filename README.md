# FunPayX

FunPayX помогает управлять аккаунтом FunPay, чатами, заказами и плагинами. Лаунчер Windows запускает ядро бота и обновляет его. Приложение Android подключается к серверу FunPayX, чтобы управлять ботом с телефона.

## Установка

- [Скачать для Windows](https://github.com/ssigmovich666-alt/projectX/releases/download/funpayx-stable/ProjectX-FunPay.exe)
- [Скачать для Android](https://github.com/ssigmovich666-alt/projectX/releases/download/funpayx-stable/FunPayX-Mobile.apk)

Активируйте ключ подписки сначала в лаунчере на ПК, затем в приложении Android. Для управления ботом с Android подключите настроенный сервер в приложении. При первой установке лаунчер Windows сам загружает ядро.

[Стабильный релиз и файлы автообновления](https://github.com/ssigmovich666-alt/projectX/releases/tag/funpayx-stable)

Ядро основано на [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal).
