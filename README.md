# FunPayX

FunPayX помогает продавцам вести магазин на FunPay. В Windows-лаунчере можно запускать бота на своём компьютере или управлять ботом на VPS, отвечать покупателям, смотреть продажи и покупки, настраивать функции и получать уведомления в Telegram.

Android-приложение подключается к панели FunPayX на VPS. С телефона можно управлять ботом, менять его функции и настройки установленных плагинов. Настройки серверного бота доступны с ПК и телефона.

## Подключение

1. Скачайте [лаунчер Windows](https://github.com/ssigmovich666-alt/projectX/releases/download/funpayx-stable/ProjectX-FunPay.exe) и активируйте ключ подписки на ПК.
2. Запустите первоначальную установку. Лаунчер загрузит базовое ядро из релиза GitHub.
3. Для управления с телефона установите [FunPayX для Android](https://github.com/ssigmovich666-alt/projectX/releases/download/funpayx-stable/FunPayX-Mobile.apk) и введите тот же ключ подписки. Затем подключитесь к панели своего VPS.

На одну подписку предусмотрены активация на одном ПК и активация на одном телефоне.

## Тарифы и плагины

| Тариф | Цена | Доступ |
| --- | ---: | --- |
| Стандарт | 299 ₽ в месяц | FunPayX |
| Стандарт+ | 499 ₽ в месяц | FunPayX и плагины из каталога |
| Стандарт навсегда | 799 ₽ | Бессрочный доступ к FunPayX |
| Стандарт+ навсегда | 999 ₽ | Бессрочный доступ к FunPayX и плагинам из каталога |

Базовое ядро устанавливается без плагинов. Лаунчер загружает плагины каталога для Стандарт+. При отдельной покупке ключ плагина вводится в разделе «Плагины» на ПК.

Лаунчер и Android-приложение проверяют обновления в [стабильном релизе GitHub](https://github.com/ssigmovich666-alt/projectX/releases/tag/funpayx-stable). Ключи, токены и пользовательские данные остаются в вашей установке FunPayX.
